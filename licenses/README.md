# The license texts

Every file here is the license file its project ships, byte for byte, fetched from
the project's own repository by `tools/fetch-licenses.py`. Nothing in this folder
was typed or edited. What each component is and what it does in AlbumWall is in
[THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md); AlbumWall's own license is
[LICENSE](../LICENSE), the GNU GPL version 3.

The audio engine's files come from exactly the versions pinned in
`scripts/build-libmpv/inner.sh`. Where a ref says *default branch*, the project's
tags could not be predicted from a package version and its license does not vary
with it; the SHA-256 says exactly which text this is.

SQLite is in the public domain and ships no license file; see
https://sqlite.org/copyright.html.
